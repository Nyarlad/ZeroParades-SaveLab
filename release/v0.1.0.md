# ZeroParades-SaveLab 0.1.0

First release candidate of an unofficial, offline save inspector/editor for Zero Parades: For Dead Spies.

The Windows ZIP contains `ZeroParades-SaveLab.exe`, `savelab-cli.exe`, user documentation and third-party licenses.
Python is bundled. The executables are unsigned. Verify the ZIP using the adjacent SHA-256 file.

Confirmed editing profile: release 1.1 / changeset 40781 / save revision 0.
Other decodable builds are inspect-only. Static validation does not guarantee arbitrary story-state edits are safe.

The initial confirmed preset is the two-stage Reno train repair: temporarily restore the ordinary conversation,
hand over the repaired train through the game, then restore the historical flag on a NEW post-handover save.
The editor does not fake inventory removal or quest completion.

Original replacement and backup restore require explicit confirmation. Every write operation has a verified backup.
There is no telemetry, upload, account connection or automatic Steam Cloud change.

This release candidate is prepared locally. Public publication requires the repository owner's separate approval.
