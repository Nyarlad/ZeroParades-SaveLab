# Инструкция для Windows

Распакуйте ZIP и запустите `ZeroParades-SaveLab.exe`. Устанавливать Python не нужно.
Инструмент неофициальный, не связан с ZA/UM. Сохранения и аналитика в сеть не отправляются.

1. **Find saves** находит стандартную папку игры. **Choose folder** позволяет выбрать другую.
2. Откройте сохранение двойным щелчком. Метаданные, версия и контрольные суммы будут проверены.
3. На вкладке **Overview & repair** выберите исправление и прочитайте описание риска.
4. **Check conditions & preview repair** покажет точный переход флага, пока без записи.
5. **Export patched copy** создаст резервную копию и проверенный отдельный файл вне папки Saves.
6. Только если хотите применить результат: закройте игру, нажмите **Apply exported copy to original** и подтвердите конкретный файл.
7. Загрузите именно этот слот в игре и проверьте результат.

Исправление Рено состоит из двух шагов. **Reno — Restore Train Dialogue** временно открывает обычный разговор.
Вручите поезд средствами игры, не повторяя сделку с кормом. Создайте НОВОЕ ручное сохранение и закройте игру.
Откройте новое сохранение в редакторе, примените **Reno — Restore Historical Flag**, чтобы вернуть исторический флаг просьбы о корме.
После второго шага Рено может снова отвечать Goodbye — поезд уже вручён, исходная маршрутизация диалога восстановлена.

Все остальные поля сохраняются. Однако временный флаг влияет и на условные реплики других разговоров: второй шаг нужен именно для его возврата.
Исправление подтверждено для сборки 1.1 / 40781, не для всех возможных сюжетных состояний.

Резервные копии находятся в `%LOCALAPPDATA%\ZeroParadesSaveLab\backups`. В каждом каталоге — `original.sav` и `record.json` с хешем и исходным именем.
На вкладке **Backups & restore** можно восстановить одну копию после подтверждения. Текущий файл также будет сохранён, даже если он повреждён.
Для ручного отката закройте игру и верните `original.sav` под исходным именем, указанным в `record.json`. Не откатывайте целиком старую папку поверх нового прогресса.

**Advanced Flag Explorer** ищет NPC, идентификаторы, значения и описания. Неизвестные флаги помечены **Unknown**.
Их изменение требует явного экспериментального режима и может нарушить зависимости сюжета. Счётчики и инвентарь доступны только для чтения.
Вкладка **Compare saves** сравнивает два файла и экспортирует diff в JSON. Такие данные могут раскрывать ваш прогресс: не публикуйте их вместе с сохранениями.

Steam Cloud и настройки игры инструмент не меняет. Если файл изменился после открытия, редактор откажется его заменять: откройте свежую версию заново.
